# Båtmekaniker

En enkel, mobilanpassad startsida för Båtmekaniker.

## Publicera med GitHub Pages
1. Öppna **Settings** i repot.
2. Välj **Pages**.
3. Under **Build and deployment**, välj **Deploy from a branch**.
4. Välj branch **main** och mapp **/(root)** och spara.

När publiceringen är klar visas webbplatsens adress under Settings → Pages.

> Webbplatsen är en informationssida. Den installerar inte automatiskt en privat ChatGPT-plugin i besökarens konto.
